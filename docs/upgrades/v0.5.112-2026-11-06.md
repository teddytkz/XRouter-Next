## Perubahan tambahan setelah cherry-pick

### OpenCode free: relay/proxy Vercel tidak boleh mem-bypass TLS

Gejala: `HTTP 429 FreeUsageLimitError` tetap muncul walau `wreq-js` aktif.
Penyebab: cabang `vercelRelayUrl` di `proxyAwareFetch` melakukan return lebih awal
memakai `originalFetch`, sehingga `options.directFetch` tidak pernah dipanggil.
Probe `/tmp/opencode-relay-probe.mjs`: `no-proxy tlsCalls=1 status=200`,
`relay-set tlsCalls=0`, `pool-set tlsCalls=1`.

Fix kode:
- `directFetch.requiresDirectTransport = true` pada `OpenCodeExecutor.execute()`.
- `proxyAwareFetch()` melewati **semua** jalur relay/proxy/env-proxy sebelum resolusi
  proxy bila transport menuntut handshake TLS sendiri; `strictProxy: true` gagal
  keras agar tidak ada request yang diam-diam keluar lewat jalur yang salah.
- Tes: `tests/unit/opencode-tls-fail-open.test.js` (relay, standard pool, strict),
  `tests/unit/opencode-tls-transport.test.js` (flag wiring).

Fix data lokal (bukan kode repo): `settings.providerStrategies.opencode.proxyPoolId`
dihapus dari `~/.9router/db/data.sqlite`; pool Vercel `reyey.vercel.app` dibiarkan
ada untuk provider lain. Backup sebelum perubahan DB:
`~/.9router/db/data.sqlite.bak-kiro-cleanup-20261106T112419Z`.

**Catatan operasional:** bila user kembali memasang relay/proxy untuk `opencode`,
kode akan melewatinya untuk transport TLS ini. Jangan "memperbaiki" 429 dengan
mengganti URL relay: HTTP relay tidak dapat mempertahankan ClientHello BoringSSL.

### MiniMax lease: keamanan local-only

`ALWAYS_PROTECTED` dan `LOCAL_ONLY_PATHS` kini menyebut eksplisit `lease`,
`lease-status`, `lease-connect` untuk `minimax-code` dan
`minimax-code-global`. Prefix `/lease` dari upstream sebenarnya sudah mencakup
dua aksi UI lewat `startsWith`, tetapi path eksplisit mencegah regresi kalau
matching diubah. Tes pada `tests/unit/dashboard-guard.test.js` mengunci:
remote → 403, loopback tanpa JWT → 401 bahkan saat `requireLogin=false`,
loopback + JWT → next.

Audit lain: router tidak menyimpan refresh token untuk koneksi
`mcode-lease`; token hasil lease hanya ada di memori/cache dan dipakai sebagai
`Authorization` pada request. Log mencatat generation/expiry, bukan nilai token.
Endpoint broker dihitung dari path absolut; capability file dibaca, frame dibatasi
64 KiB, dan refresh tetap menjadi tanggung jawab aplikasi desktop.

**Peringatan keamanan:** fitur ini berbicara ke named-pipe/unix-socket broker di
host yang sama dan meminjam kredensial desktop. Endpoint lease wajib tetap
local-only + JWT/CLI-token; jangan mengekspos route ini lewat tunnel, dan jangan
menaruh `data_dir`/capability/token ke log atau respons klien.
`custom-server.js` tetap menjadi sumber kepercayaan peer IP dan stripping
`X-Forwarded-For`; jangan memindahkan pemeriksaan lokal ke header yang bisa
dikirim klien.
